# 参与 MetaFight

欢迎提交可复现的问题、触控体验建议与小范围 PR。

## 提交问题

请说明游戏版本、设备型号、系统和浏览器／小红书版本，写清从开始页到问题出现的步骤、预期与实际结果。截图请移除账号、通知、位置等私人信息。不要把密码、访问令牌或私人二维码放进 Issue。

## 修改代码

1. Fork 并新建分支，按 README 安装依赖。
2. 用 `npm start` 检查行为，用 `npm run verify` 完成回归。
3. 在 PR 中说明解决的问题、可观察的变化、验证环境；视觉变更附真实游戏截图。

玩法、人数、地图碰撞和出生规则属于产品基线，大幅改变请先开 Issue 讨论。小红书适配不能破坏独立网页构建；无需提交官方 SDK / Skill、node_modules、构建包或内部验收记录。

新资源请补充来源和使用许可，保留 WebReal 的 MIT 声明。涉及手机性能时写明真实设备与测量方法，不用桌面模拟数据代替。
