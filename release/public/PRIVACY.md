# 隐私与本地数据

游戏没有独立账号或第三方统计，不主动上传游戏对局、操作或错误记录，不请求相册、摄像头、麦克风、定位或通讯录权限。

音量、灵敏度、画质、瞄准辅助及引导完成状态保存在本地；网页用浏览器存储，小红书优先用宿主存储，能力不满足时回退到容器本地存储。对局保存在内存，关闭后不恢复。不进行跨渠道云同步。恢复默认可重置设置；浏览器或宿主清除对应数据后，保存的偏好会丢失，宿主的保留规则以平台为准。

静态托管方可能记录文件访问IP、时间等；小红书账号、分发和宿主服务按其自身规则处理。游戏无法控制这些服务日志。用户主动提交的评论或 Issues 按对应平台规则处理，不应附带私人信息。游戏不会自动把运行数据填入反馈。
